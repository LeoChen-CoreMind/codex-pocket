# README 展示图片上传说明

根目录 `README.md` 已经直接引用本目录中的五张图片，其中包括四张 Android APP 图片和一张 Windows 服务端图片。只要按下面的固定文件名上传，GitHub 项目首页就会自动显示图片，客户不需要进入本目录查看。

## Android APP 图片

| 文件名 | README 展示位置 | 必须展示的内容 |
| --- | --- | --- |
| `online-sessions.png` | APP 第一排左侧 | 打开 APP 侧边栏并停留在“在线列表”；至少显示一个在线会话，以及对应的编辑器名称和工作区 |
| `chat-control.png` | APP 第一排中间 | 打开一个正在运行的对话；显示用户消息、Codex 回复或工具调用、输入框、发送/停止按钮，最好同时出现一个队列项及“引导”操作 |
| `approval.png` | APP 第一排右侧 | 打开带有计划确认、命令审批或权限审批的对话；审批内容和允许/拒绝操作必须完整可见 |
| `mcp-dialog.png` | APP 第二排 | 展示手机实际收到的 MCP 请求；优先选择同时包含 Markdown、图片和选择项的画面，也可以展示自由文本输入 |

## Windows 服务端图片

| 文件名 | README 展示位置 | 必须展示的内容 |
| --- | --- | --- |
| `server-console.png` | 服务端大图 | 完整的 `Codex Pocket Bridge` 控制器窗口；显示 Bridge/Codex/FRP 状态、局域网 IP、监听地址、监听程序、在线编辑器、在线对话以及“应用并启动”“复制连接信息”等按钮 |

建议规格：

- 四张 APP 截图使用纵向 PNG，推荐 `1080 x 2400`，图片尽量保持相同尺寸和同一种明暗主题。
- `mcp-dialog.png` 可使用完整手机纵向截图。
- 服务端截图使用 Windows 控制器原始窗口比例，保留完整窗口边界，文字应当清晰可读。
- 文件扩展名必须是小写 `.png`，名称必须与表格完全一致。

上传前必须遮挡或替换以下信息：

- Bridge 访问密钥和 MCP Bearer Token
- 局域网 IP、公网地址和 FRP 配置
- Windows 用户名、绝对路径和设备名称
- 私人会话内容、私有仓库名称和未公开工作区名称

上传后直接访问仓库首页检查图片排版即可，不需要修改根目录 README。
